# 正畸随访助手 · SoftwareInnovation

面向接受正畸治疗的大学生。项目拟让用户在两次复诊之间按引导拍少量照片，用首次口扫建立的逐牙模型查看本期外观和位置，记录自己的感受，并把选定的记录交给负责医生复核。

**当前处于产品设计和软件工程搭建阶段（2026-11-20）。** 已有三维研究原型位于独立科研工程。第一个软件里程碑是可安装的 Android Alpha，队友可以按说明安装，用演示样例走完查看模型和再次打开记录的流程。

| 从哪里开始 | 用途 |
|---|---|
| [初步项目计划书](docs/项目计划书.md) | 产品场景、创新假设、技术方案和可行性 |
| [四人分工与软件交付计划](docs/分工与排期.md) | 认领产品、客户端、系统集成、算法工程职责，按里程碑验收 |
| [参赛依据](docs/参赛依据.md) | 题面、截止时间、评分与提交材料 |
| [数据交接示例](examples/visit.synthetic.json) | 使用虚构随访记录并行开发 |
| [仓库结构与分批提交](docs/仓库结构与分批提交.md) | 各模块放在哪里、科研代码如何迁入 |
| [纹理基线与替换方法](algorithms/texture/README.md) | 当前采用的整排方案、修改效果时的对照 |

协作方式：一项可演示的改动使用一个短分支，通过 PR 写明输入、实际输出和验证方法。合并前请接收这个输出的队友试一次。仓库只放团队可分享的代码、文档和明确标注的合成样例。开发机上的私人材料统一放到忽略的 `.local/` 中。提交前查看暂存差异，尤其留意截图、模型纹理、目录中的身份标识与密钥。
