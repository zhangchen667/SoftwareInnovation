# 第二十届全国大学生软件创新大赛参赛依据

核对日期为 2026-11-20。队长应在报名前复查本赛区和校内安排。若队长学校在湖北，按总通知归华南赛区。

| 核对项 | 对团队的影响 |
|---|---|
| 资格 | 1 名学生队长、至多 3 名其他学生、至多 2 名指导教师。每名学生限一队，每队一件作品。按指定赛题报名。 |
| 初赛 | 报名与区域初赛作品均截至北京时间 **2027-01-15 18:00**。必交项目计划书，Beta 可运行程序及源码、介绍视频可选。报名资格材料另按报名系统办理。 |
| 评审 | 附件八第 2 页给出初赛权重：创新性 40、应用价值 20、软件技术 25、软件工程质量 15。准备访谈证据、同类方案对照、技术验证和交接记录。 |
| 平台 | 手机展示须基于 Android 开发。全国决赛有 OPPO 终端支持，部分能力在区域复赛可申请。前期按能实际借到的设备排期。 |
| 原创与匿名 | 核心工作和关键组件应在本届期间完成，核对过往参赛情况和研究资产权属，列出继承、自研与第三方实现。作品材料须隐藏学校和成员姓名，送评包也检查 Git 地址、截图、文件元数据。 |
| 后续 | 区域复赛及决赛需设计与创新分析、技术研究、开发及测试文档、Beta 程序与源码、实机展示视频。各区另发细则。 |

**赛题四的适配判断。** 附件一第 9–11 页要求从真实生活场景呈现身心状态理解、个性化支持和兴趣探索。至少走通用户了解状态、获得选项、做出选择并反馈后得到调整的过程，穿戴设备须有实际作用。具体设备组合和示例可按任务选择。材料还需说明数据取得时间、缺失和模拟情况、AI 的实际贡献，以及用户访谈和试用如何改变设计。用户可调整提醒、管理记录及授权。

目前构想覆盖口腔记录、可视化和医生协作。单靠照片和三维时间线，仍缺穿戴交互、兴趣探索和据反馈调整的证据。本周应确认真实需求及设备可用性，拿场景向指导教师或组委会咨询。这里的产品场景是团队候选方案，契合程度尚待反馈。
